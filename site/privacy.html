Privacy

What happens to your files

Short version: we look at the file long enough to answer you, then it's gone.

Files you upload

  • Each file is written to a private temporary folder on the scanning server, processed, and the folder is deleted before the response is sent back to you.
  • We don't keep copies, thumbnails, hashes or reports. The clean copy is sent straight to your browser and isn't stored.
  • Filenames are never logged. The scanning server has access logging turned off.

What we collect

  • No cookies, no analytics, no tracking pixels, no third-party scripts or fonts.
  • This site is served by Cloudflare, which handles the connection and can see traffic passing through it. Cloudflare's own privacy policy applies to that.

AI features

AI features aren't live yet. When they are, they'll only run when you press an AI button, only on that file, with metadata stripped first, and this page will name the exact model provider.

Payments

Paid features aren't live yet. When they are, you'll get a token instead of an account. We'll store a hash of the token and its balance, and nothing that links it to you or to your files.

Don't want to trust any server?

Then don't. The whole tool is open source and runs offline: pip install "unredact-tools[web]", then unredact.tools web.
