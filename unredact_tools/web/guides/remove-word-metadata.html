What a Word file keeps

A .docx file is a zip archive of XML files, and only some of them are the text you see. The rest can include:

  • Names: author, last modified by, manager and company.
  • Tracked changes: every deletion still in the file, with who made it and when.
  • Comments, with commenters' names and sometimes their email addresses.
  • Hidden text: text formatted as hidden, white on white, or shrunk too small to see.
  • File paths to the template or linked data, which often contain your username, like C:\Users\jsmith\…, or an internal server or SharePoint address.
  • Session IDs Word adds to each editing session, which can show that two documents came from the same draft.
  • Editing statistics: total editing time, revision count and when it was last printed.
  • Your organization's Microsoft 365 tenant ID, left behind by sensitivity labels.
  • Photos inside the document, which keep their own GPS and camera data.

Excel and PowerPoint too

Spreadsheets can carry hidden sheets, rows and columns, and pivot caches that still hold data deleted from the visible sheet. Presentations keep speaker notes and hidden slides. XLSX and PPTX files, and their macro-enabled versions, are checked and cleaned the same way.

What about Word's Document Inspector?

Office's built-in Document Inspector covers a lot of this, if you remember to run it every time. It doesn't show you what it found in plain terms, and it leaves the photos inside the document with their own metadata. This tool shows you what the file gives away before you change anything, then checks the clean copy again.

What cleaning does

  • Empties author, company and other properties.
  • Accepts all tracked changes, so deleted text is really gone. If you meant to reject some changes, do that in Word first.
  • Deletes comments, the list of people who edited the file, and speaker notes.
  • Removes hidden text and editing session IDs.
  • Clears template and data-source paths.
  • Unhides hidden sheets, rows and slides, so you can see everything you're about to send.
  • Cleans the photos and media inside the document.
  • Resets the timestamps inside the zip archive.

Older .doc, .xls and .ppt files aren't supported. Save them in the newer format first.
