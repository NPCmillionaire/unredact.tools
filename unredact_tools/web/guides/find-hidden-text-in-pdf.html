Where text hides in a PDF

  • Invisible formatting: white text on a white page, fully transparent text, or text set at a fraction of a point.
  • Off the page: text placed outside the visible page area. It's still in the file and still selectable.
  • Under black boxes: failed redactions, where a shape covers words that were never removed.
  • Hidden layers: PDFs can have layers that are switched off by default.
  • Earlier versions: edits are often added to the end of the file, so the original text can still be inside. The scan rebuilds every saved version and lists the text deleted since.
  • Attachments: files embedded in the PDF, each scanned in turn.
  • Comments and annotations, including ones that aren't shown.

Invisible characters

Some hidden text isn't hidden by formatting at all. It's made of characters that take up no space:

  • Zero-width characters can be scattered through a document so every copy is slightly different. When one leaks, the pattern shows whose copy it was. This is called a canary trap.
  • Unicode tag characters can carry a whole hidden message, invisible on screen. The scan decodes it and shows you what it says.
  • Look-alike letters: Cyrillic or Greek characters swapped in for Latin ones that look identical, another way to mark individual copies.

These work in text files too, not just PDFs.

Why it matters

If you're sending a file, hidden text can reveal what you thought you'd removed, and tracking marks can tie the file back to you.

If you received one, hidden text can be aimed at whoever, or whatever, reads it next: keywords stuffed into a resume for screening software, or instructions hidden for AI tools that summarize the document.
