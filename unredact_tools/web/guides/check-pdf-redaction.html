Why PDF redactions fail

A PDF stores text and drawings as separate layers. Putting a black shape on top of a sentence hides it from your eyes but leaves the sentence in the file, where anyone can select it, copy it or search for it. The common mistakes:

  • Drawn boxes. A black rectangle, or black highlighting, placed over the text with a drawing or comment tool.
  • Black images. A black picture pasted over the words. The text layer underneath is untouched.
  • Unapplied redactions. Redaction tools in PDF editors usually work in two steps: mark the areas, then apply. If the file is saved after marking but before applying, the text is still there.
  • Scanned pages with a text layer. Scans often have an invisible OCR text layer. Blacking out the image doesn't touch that layer.
  • Earlier versions. Many editors save changes by adding them to the end of the file. The version from before the redaction can still be inside, complete.

The quick check you can do by hand

Open the PDF, select all the text on a redacted page, copy it and paste it into a plain text editor. Or search the PDF for a word you know you redacted. If it shows up, the redaction failed.

That catches the most common failure but misses others: earlier versions saved inside the file, hidden layers, attachments and metadata such as the author's name or a file path containing a username. The scan above checks for all of them.

What the scan checks

  • Text still present under black boxes, black images and unapplied redaction marks, with the words it finds underneath.
  • Earlier versions of the file, with a list of the text deleted since.
  • White, transparent, microscopic and off-page text.
  • Hidden layers, attachments and embedded files, each scanned in turn.
  • Author, creating software, document IDs and usernames in file paths.
  • Metadata inside the images in the PDF, which keep their own GPS and camera data.
  • Printer tracking dots on scanned pages.

Two ways to fix it

Flatten to images (the default) renders every page to a picture and builds a new PDF from those pictures. Nothing survives except what you could see on screen. Use this when the stakes are real.

Keep selectable text is for when the PDF has to stay searchable, like a court filing or a published report. It removes the text under every detected black box for real, strips hidden text, annotations, JavaScript, attachments and metadata, rewrites the file so earlier versions are gone, and gives it a fresh document ID.

Either way, the clean copy is scanned again before you download it.

It has happened to lawyers and governments

In 2019, Paul Manafort's lawyers filed a court document with black boxes over text that was still in the file. Reporters copied it out within hours and learned he was accused of sharing campaign polling data. In 2009, the TSA posted a screening procedures manual online with redactions that could be copied out the same way. More cases like these.
