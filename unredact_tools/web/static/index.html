See what your files give away.

GPS coordinates, device serials, author names, black boxes that don't actually hide anything, deleted tracked changes, printer tracking dots. Drop a file to see what it leaks, then download a copy with all of it removed.

Drop files here or click to choose

JPEG · PNG · HEIC · WebP · TIFF · PDF · DOCX · XLSX · PPTX · MP4 · MOV · MP3 · text

Files are processed in a temporary folder that is deleted before the response is sent. Nothing is stored or logged. For anything truly sensitive, run it yourself: pip install "unredact-tools[web]" && unredact.tools web
