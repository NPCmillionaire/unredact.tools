Privacy

What happens to your files.

Short version: the website looks at a file long enough to answer you, then it's gone. The Chrome extension never sends your files anywhere.

Files you upload to the website

  • Each file is written to a private temporary folder on the scanning server, processed, and the folder is deleted before the response is sent back to you.
  • We don't keep copies, thumbnails, hashes or reports. The clean copy is sent straight to your browser and isn't stored.
  • Filenames are never logged. The scanning server has access logging turned off.

The Chrome extension

The extension scans and cleans files inside your browser, on your device. It has no server, no account and no analytics.

  • Files are never uploaded by the extension. When you right-click a file and choose “Inspect with unredact.tools”, the extension downloads that one file from the site it's on, the same way your browser would, and reads it locally. When it checks an upload on a protected site, it reads the file you picked before the site does. Either way the file stays in your browser's memory and is discarded when you close the report or after 15 minutes.
  • What it stores: only your settings (which sites are protected, your own added sites, severity and size limits). They're kept in Chrome's extension storage on your device.
  • What it reads on web pages: on protected sites it watches for file pickers and dropped files. It doesn't read, collect or transmit page content, messages, browsing history or anything you type.
  • Why it asks for access to all websites: so it can fetch any file you right-click, wherever it's hosted, and so it can protect sites you add yourself. It acts only when you right-click a file or upload on a protected site.
  • Deep scan (optional): if you run unredact.tools web on your own computer and press “Deep scan”, the extension sends the file to that local address (by default 127.0.0.1, which never leaves your machine). If you point it at another address, the file goes there instead.
  • We don't sell, share or transfer any data, because the extension doesn't send us any.

What we collect on the website

  • No cookies, no analytics, no tracking pixels, no third-party scripts or fonts.
  • This site is served through Cloudflare, which handles the connection and can see traffic passing through it. Cloudflare's own privacy policy applies to that.

Don't want to trust any server?

Then don't. The whole tool, extension included, is open source and runs offline: pip install "unredact-tools[web]", then unredact.tools web.
