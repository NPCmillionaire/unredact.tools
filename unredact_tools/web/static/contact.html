Get in touch

Questions, feedback, a leak the scanner missed, or a security problem with the site. Send a message below and it comes straight to my inbox.

Messages are emailed to me and not stored on this site. Leave your name and email blank to stay anonymous, but then I can't write back.

Reporting a missed leak

If a file gave away something the scan didn't catch, or a clean copy still had something in it, tell me the file type, what leaked and where it showed up. Please don't attach the real file if it's sensitive. A harmless file that reproduces the problem is far better.

Security issues

If you find a vulnerability in the site or the tool, email me before you disclose it publicly so it can be fixed first.

Bugs and feature requests
