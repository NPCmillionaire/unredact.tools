Chrome extension

Check files before you send them.

The same checks as this site, built into your browser. When you attach a photo, PDF or Office file on an email, chat, social or cloud storage site, it's scanned first. If it leaks, you choose: Clean & Upload, Upload Original, or Cancel.

⏳Waiting for Chrome Web Store approval. Until it's listed, you can install it by hand in about two minutes. You'll get the same extension the store will have.
Download the extension (.zip) v0.1.2 · 1.3 MB · Chrome, Edge, Brave, Arc, Vivaldi

Install it

  1. Download the zip above and unzip it (double-click it on a Mac, or right-click → Extract All on Windows). You'll get a folder called unredact-tools-chrome-0.1.2. Move it somewhere you'll keep it, like your Documents folder. If you delete it, the extension stops working.
  2. Open the extensions page. Type chrome://extensions into the address bar and press Enter. In Edge it's edge://extensions, in Brave brave://extensions.
  3. Turn on Developer mode with the switch in the top-right corner (in Edge it's in the left sidebar).
  4. Click “Load unpacked” and choose the folder from step 1, the one with manifest.json inside.
  5. Pin it (optional): click the puzzle-piece icon in the toolbar, then the pin next to unredact.tools.
  6. Reload any tabs that were already open, such as your email or chat, so the upload check can start there.

That's it. A settings page opens with the list of protected sites. Every site can be turned off, and you can add your own from the toolbar button.

What it does

  • Clean before send. Uploads through the file picker or drag-and-drop are held for a moment and scanned. Clean files go straight through; leaky ones get a short warning listing what they give away.
  • Right-click to inspect. Right-click any image, PDF, video or download link and choose “Inspect with unredact.tools” to see what a file you found online reveals, without saving it first.
  • Finds: GPS, names, device serial numbers and uncropped thumbnails in photos. Text under black boxes, deleted text from earlier versions, and attachments in PDFs. Comments, tracked changes, hidden text and speaker notes in Word, Excel and PowerPoint.

Private by design

Everything runs inside your browser. No file is uploaded to us or anyone else, there's no account and no analytics. Details are on the privacy page, and the code is on GitHub.

Good to know

  • “Disable developer mode extensions”: Chrome may show this reminder for extensions installed by hand. Click away from it, not on Disable. It stops once the store version is out.
  • Updates aren't automatic for a hand-installed copy. When the store listing goes live, remove this copy and install from the store to get updates.
  • Check the download (optional). SHA-256 of the zip: 69a58480eb268005f60ae147c393f3ab9364e66fdeca37c9e0eb8cad49feb9ee
  • Firefox and Safari aren't supported yet. Use the website or pip install "unredact-tools[web]" in the meantime.
