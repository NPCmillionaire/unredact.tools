About

If you send this, what does the other person learn about you?

unredact.tools answers that question for any photo, PDF, Office document or media file, then gives you a copy that answers “nothing.”

Files say more than they show

Every file carries more than what's on screen: GPS coordinates, camera serial numbers, usernames, earlier drafts, deleted text, comments, and invisible watermarks that identify exactly whose copy leaked. Most of it is added without you ever seeing it.

People get caught this way

YearWhat happened
2012John McAfee was located while hiding from authorities, from the GPS data in a photo a journalist posted.
2017The source of a leaked NSA document was identified from printer tracking dots on the scan, which revealed the printer and when it printed.
2019Paul Manafort's lawyers filed a “redacted” PDF with black boxes drawn over text that was still there. Reporters copied it out within minutes.
AlwaysTracked changes, comments, author usernames and earlier saved versions ride along in everyday Office and PDF files.

What it does

  • Scan. Finds what's leaking and explains it in plain English: where, who, which device, when, what software, which organization, what's hidden and what's tracking you.
  • Sanitize. Rebuilds a clean copy from the visible content only, then re-scans that copy to prove nothing survived. Your original file is never modified.

Good tools already exist (ExifTool, mat2, Dangerzone), but each does one job and none of them explains the risk. unredact.tools does detection, explanation and cleaning in one place.

Your files

Uploads are processed in a temporary folder that is deleted before the response is sent. Nothing is stored or logged, and the site uses no cookies, analytics or third-party scripts. For anything truly sensitive, run it on your own machine instead:

pip install "unredact-tools[web]" && unredact.tools web
